# Luxe Travel

Сайт турагентства из Караганды. Здесь можно посмотреть горящие туры, выбрать страну и отель и сразу написать менеджеру в WhatsApp.

**Открыть сайт:** https://chpokvpopok.github.io/luxe-travel/

![Главная страница](docs/screenshot-home.png)

## Что есть на сайте

- **Горящие туры:** актуальные предложения с датой вылета, ценой и списком отелей.
- **Направления:** Вьетнам, Хайнань, Таиланд, Оман, Турция, Мальдивы и другие. Для каждой страны есть сезон, курорты, время перелёта и визовые правила.
- **Отели:** подборка отелей с короткими обзорами.
- **Подбор тура:** указываете страну, город вылета, даты, кто едет и бюджет, и заявка сразу уходит в WhatsApp.
- **Услуги, ответы на частые вопросы и контакты офиса.**

Сайт удобно смотреть и с телефона. Второстепенные разделы убраны в боковое меню, чтобы шапка не была перегружена:

![Боковое меню](docs/screenshot-menu.png)

## Как сделан

Простой сайт на HTML, CSS и JavaScript, без фреймворков. Тёмная тема с золотыми акцентами, шрифты Cormorant Garamond и Manrope. Размещён на GitHub Pages.
