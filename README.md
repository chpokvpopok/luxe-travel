# Luxe Travel

Сайт турагентства Luxe Travel (Караганда): горящие туры, направления, отели, услуги и контакты. Заявки уходят в WhatsApp менеджеру.

Сайт: https://chpokvpopok.github.io/luxe-travel/

Статический сайт на чистом HTML, CSS и JavaScript, без сборки и зависимостей.

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Главная |
| `tours.html` | Горящие туры |
| `directions.html` | Все направления |
| `country.html?id=…` | Страница страны (`id` из `DIRECTIONS`) |
| `hotels.html` | Отели |
| `services.html` | Услуги |
| `about.html` | О нас |
| `faq.html` | Вопросы и ответы |
| `contacts.html` | Контакты |

## Структура

```
assets/
  css/style.css   — все стили; цвета задаются переменными в :root
  js/data.js      — контент: контакты, туры, отели, направления, отзывы
  js/main.js      — общий код: шапка с боковым меню, подвал, карточки, формы → WhatsApp
```

Шапку и подвал на каждой странице вставляет `main.js`, поэтому меню правится в одном месте.

## Как обновить контент

Почти всё меняется в `assets/js/data.js`, HTML трогать не нужно.

- **`SITE`**: номер WhatsApp (`waPhone`, только цифры), телефоны, адрес, часы работы, Instagram, 2ГИС.
- **`OFFERS`**: горящие туры. `country` — это `id` страны из `DIRECTIONS`, `city` — город вылета (`astana`, `almaty`, `aktau`). Если не указать `price`, на карточке будет «Цена по запросу».
- **`HOTELS`**: отели с описанием и звёздностью.
- **`DIRECTIONS`**: страны с курортами, сезоном, визой и временем перелёта. Каждой стране отдельная страница `country.html?id=<id>`.
- **`REVIEWS`**: отзывы.

Меню задаётся массивом `NAV` в начале `main.js`. Пункты с `main: true` видны в шапке, остальные открываются в боковой панели по кнопке «Меню». На телефоне в панели показываются все разделы.

## Запуск локально

Откройте `index.html` в браузере. Или запустите локальный сервер:

```
python -m http.server 8000
```

и перейдите на http://localhost:8000

## Публикация

Сайт размещён на GitHub Pages из ветки `main` (Settings → Pages). Чтобы опубликовать изменения:

```
git add .
git commit -m "Описание изменений"
git push
```

Сайт обновится примерно через минуту.

## Перед запуском проверить

- [ ] Заменить заглушки в `REVIEWS` на реальные отзывы (из сторис или 2ГИС).
- [ ] Сверить визовые правила и время перелёта в `DIRECTIONS`: они указаны ориентировочно.
